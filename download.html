Download MassOS

You can download MassOS now, to try it out and/or install it on your PC.

The release notes for all stable versions of MassOS, as well as the current development build(s), can be found here.

Each release will have both a Live ISO image and a Rootfs tarball. Most users will want the Live ISO image, which can be written to a USB flash drive, and provides a bootable live environment for trying out MassOS without making any changes to your computer. Once you've tried out the live environment and are ready to fully install MassOS onto your computer, a graphical installation program is provided on the live system which guides you through this process.

By contrast, the Rootfs tarball is only useful for those who wish to manually install MassOS (which is not recommended), or for performing an offline update with the new MassOS upgrade utility (as opposed to the utility's default mechanism of performing online updates using the MassOS upgrade server).

Stable release - 2026.09

The stable release is the recommended choice for most users. New stable releases are published at least once a month. Updating an existing installation can be done using the new MassOS upgrade utility when configured for the "stable" channel.

This version of MassOS includes Linux kernel 7.2.2.

Development build - 2026.09

Development builds are produced fairly frequently, to test upcoming changes and updates before they reach stable releases. These builds are only recommended for experienced users, as they are significantly more likely to encounter stability and/or usability issues. Updating an existing installation can be done using the new MassOS upgrade utility. Systems running stable builds can be updated in-place to development builds by (re)configuring the upgrade utility to use the "experimental" channel instead of "stable".

NOTICE: Due to the latest stable release being very recent, a development build newer than the current stable version of MassOS does not currently exist. Therefore, these downloads point to the same builds as the current stable version. Please check back soon for newer development builds as the development cycle for the next version of MassOS will commence soon.

Additional notes

All builds, including older releases, are available from this web server. Please note that we no longer provide images without firmware - all rootfs and ISO images now contain firmware by default. Please see this for more information as well as the rationale behind this decision.

After downloading, please read Installing MassOS for a detailed guide on how to create a bootable USB flash drive and install MassOS onto your computer. The installation guide also provides information on how to use the checksum and/or signature file(s) to verify the integrity of your download.

MassOS supports UEFI Secure Boot, however if your system uses it, you may need to perform some additional steps before and after installing MassOS - see the UEFI Secure Boot documentation article for more information.

At the time of writing, x86_64 is the only fully supported architecture. aarch64 is under heavy development and the aarch64 MassOS images may not (yet) be compatible with all systems, nor fully stable even on "supported" systems. Please see this page in the MassOS documentation for more information about supported architectures.
